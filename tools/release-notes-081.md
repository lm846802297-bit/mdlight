## v0.8.1 — 效率与排版增强

在 v0.8.0（PPT 演示模式）基础上新增 9 项功能：

| 功能 | 说明 |
| --- | --- |
| mermaid SVG 缓存 | FNV-1a 内容指纹 + 主题存入 localStorage，同文档二次打开图表零等待（上限 300 条自动修剪） |
| 系统字体探测 | `document.fonts.check()` 枚举已装字体，字体下拉框优先列出实际可用项 |
| PDF 页眉页脚宏 | 导出 PDF 支持 `{title}`/`{page}`/`{total}`/`{date}` 占位符，可自定义页眉页脚文本 |
| 出版级分页规则 | `orphans/widows:3`、标题不压页尾、代码/表格/图表不跨页切断 |
| 自定义快捷键 | Ctrl+K 打开快捷键管理面板，任意功能可重绑定，一键恢复默认，持久保存 |
| 拖拽打开 | 桌面拖 .md 文件进窗口直接打开（native 走服务端换文档，静态模式给出提示） |
| 单实例 + CLI 热发送 | 已开着的 mdlight 再次启动会自动转发给已有实例（Named Pipe），不另起窗口 |
| 多文档标签页 | 顶栏标签条并排多个 .md，× 关闭、点击切换，状态持久化 |
| 母版版式 | 流式 / A4 / 幻灯片三套排版模板，设置面板一键切换 |
| 虚拟滚动 | 超长文档（>200 个块）懒渲染，滚到才画 |

**修复**
- Web Worker 改 fetch+Blob 加载，Node 宿主补 `/assets/renderer.js` 路由，双宿主渲染一致性（parity 12/12）
- 标签页 IIFE 参数 `t` 遮蔽 i18n 函数 `t()` 的运行时崩溃

**构建**
- exe 6.97 MB（三处同步 md5 一致），437 + 24 项断言全绿

下载 `mdlight.exe`（单文件自足，双击即用，不装 Node / 不装浏览器内核）。
